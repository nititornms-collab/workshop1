# Homework Assignment 4 — TypeScript OOP

This project contains the requested Assignment 4 exercises:

- **Assignment 4.1:** `Student` class in `student_class.ts`, with `addScore()` and `getAverage()`.
- **Part 1:** `findLowStockItems()` function using an array filter.
- **Part 2:** `Product` class with `sell()` and `restock()` methods.
- **Part 3:** `Hero` class with `addItem()` and `useItem()` methods.
- **Part 4:** `takeDamage()` method, including the Game Over message when HP reaches zero.

## Run the project

Install Node.js first, then open a terminal in this folder and run:

```bash
npm install
npx ts-node index.ts
```

Check TypeScript types with:

```bash
npx tsc --noEmit
```
